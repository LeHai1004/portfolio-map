# Đặc tả trước, code sau

Trước khi code một thẻ, viết vào `plans/<tên-thẻ>.md`:

1. Mục tiêu (1 đến 2 câu).
2. Ai dùng (Khách, Student, Company, Admin).
3. API liên quan: đường dẫn, JSON vào ra, mã lỗi.
4. Danh sách file sẽ tạo hoặc sửa.
5. Cách kiểm tra khi xong.
6. Câu hỏi còn mở.

Không code khi chưa rõ mục 3 và 4. Việc quá 3 ngày thì cắt nhỏ thành nhiều thẻ.
